# Veritaso

Measure Learning. Build Consistency.

Veritaso is an AI-powered study improvement platform that helps students track study sessions, analyze learning patterns, generate personalized study plans, and receive actionable insights for continuous improvement.

## Planned Features

- User Authentication
- Study Session Tracking
- Analytics Dashboard
- Focus Score
- AI Study Planner
- AI Weekly Reports
- Learning Insights

## Tech Stack

### Frontend
- React
- Tailwind CSS

### Backend
- Spring Boot
- Spring Security
- JWT

### Database
- MySQL

### AI
- Gemini API
